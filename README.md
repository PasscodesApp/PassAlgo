# PassAlgo

Shared algorithms and utilities used across Passcodes applications.

## Purpose

PassAlgo contains platform-independent TypeScript code that must remain
consistent across Passcodes applications & platform.

## Rules

- No React
- No React Native
- No Expo
- No Electron
- No platform-specific APIs
- No UI components
- No UI state
- No application-specific hooks

Code in this repository should be usable by any JavaScript/TypeScript
environment.

## Examples

- Password generation
- Date formatting
- Import/export algorithms
- Validation
